# 폰트 노트 MCP 서버

내가 정리한 한국어 폰트 노트(`data/fonts.csv`)를 Claude가 읽고 폰트를 추천할 수 있게 해 주는 서버예요.
**읽기 전용**이에요. 노트를 쓰거나 지우는 기능은 없어요.

## 할 수 있는 것 (도구 3개)

| 도구 | 하는 일 | 이렇게 물어보세요 |
|---|---|---|
| `find_fonts` (폰트_찾기) | 분위기 · 용도로 폰트 찾기 | "포스터용 귀여운 폰트 추천해 줘" |
| `font_detail` (폰트_상세) | 폰트 하나의 모든 정보 보기 | "Pretendard 어때?" |
| `font_of_the_day` (오늘의_폰트) | 날짜마다 폰트 하나 소개 | "오늘의 폰트 알려 줘" |

- 내가 쓴 한줄평을 우선 참고해서 추천해요.
- 노트에 없는 폰트는 "노트에 없는 폰트예요"라고 답하고, 정보를 지어내지 않아요.

## 처음 한 번만: 준비하기

1. Python 3.14를 설치해요.
2. 이 폴더에서 터미널을 열고 아래 명령을 실행해요.
   ```
   pip install -r requirements.txt
   ```

## 사용법: Claude Code에서 쓰기

1. 이 폴더에서 Claude Code를 실행해요.
2. `.mcp.json`에 서버가 등록돼 있어서 자동으로 켜져요.
3. 처음에 "font 서버를 사용할까요?"라고 물으면 허용해요.
4. 연결 상태는 Claude Code에서 `/mcp`를 입력하면 볼 수 있어요.

## 폰트 추가 · 수정하기

- `data/fonts.csv`를 엑셀이나 메모장으로 열어 고치고 저장하면 돼요.
- 서버가 매번 새로 읽어서 바로 반영돼요. 재시작하지 않아도 돼요.
- 칸 순서는 `폰트이름, 분류, 분위기, 추천용도, 무료여부, 메모, 한줄평`이에요.
- 첫 줄(칸 이름)은 바꾸지 마세요.
- 한줄평을 비워 두면 "아직 안 써 봄"으로 보여요.
- 저장할 때는 **CSV UTF-8** 형식으로 저장해야 한글이 깨지지 않아요.

## (참고) 주소(HTTP)로 실행하기

웹 주소로 서버를 켜야 할 때만 쓰는 방법이에요. 평소에는 필요 없어요.
```
python mcp/font_server.py --http
```
- 주소는 `http://127.0.0.1:8000/mcp`예요.
- 이 주소는 내 PC 안에서만 열려요.
- 끄려면 터미널에서 `Ctrl + C`를 눌러요.

## 파일 구성

| 파일 | 설명 |
|---|---|
| `mcp/font_server.py` | 서버 코드 |
| `data/fonts.csv` | 폰트 노트 (직접 관리) |
| `requirements.txt` | 필요한 프로그램 목록 (mcp 2.3.0) |
| `.mcp.json` | Claude Code 연결 설정 |
